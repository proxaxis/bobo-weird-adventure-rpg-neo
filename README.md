# 終末サバイバル x 育成 x RPG

奪い合うか、絆を紡ぐか ――

ウイルスと放射能に汚染された荒廃世界で、自律思考する少女型 NPC と心を通わせ、共に生き抜くマルチプレイ俯瞰型RPG

## 1. ゲーム概要

### プロローグ
文明が崩壊した世界. シェルターの外には、致死性のウイルス、極限の放射能、そして変異クリーチャーが徘徊している. 生き残るために必要なのは、各地に点在する未知のエネルギー結晶 "ボイド" のみ.

人々はボイドを求めて彷徨い、奪い合い、殺し合う. 孤独に生きることも可能だが、過酷な汚染環境下での単独生存には限界がある. 生き延びる唯一の鍵は、外の世界で出会う自律型NPCたちと対話し、信頼を獲得して仲間になってもらうこと.

### ゲームループ
1. **探索 x サバイバル** - 汚染度やクリーチャーを警戒しながら、荒廃した大地を探索しボイドを収集.
2. **対話 x 育成** - フィールド上の NPC と 1 対 1 で対話. テキスト入力で語りかけ、信頼関係を構築して仲間にスカウト.
3. **マルチプレイ x 奪い合い** - オンライン上の他プレイヤーとリアルタイムで遭遇. 協力してボイドを分け合うか、力で略奪するかはプレイヤー次第.

## 2. 主な特徴

- **心を持つコンパニオン NPC**  
  固定の選択肢はありません. プレイヤーの自由入力テキストに対し、AI が文脈や関係性や感情を汲み取って応答します. 人間的なためらい、相槌、話題提案も備えています.
- **1,000 個のマイクロパラメータシステム**  
  ウイルス感染度や放射能蓄積などの生体情報、プレイヤーへの信頼度、戦闘思考、倫理観、好みに至るまで、AI の心と身体を 1,000 個のパラメータでリアルタイムにシミュレート. プレイヤーの接し方によって唯一無二の相棒へ育ちます.
- **2D フィールド × 3D VRM のハイブリッド表現**  
  フィールド探索はレトロかつ軽快な 2D 俯瞰ドット絵. 会話が始まると、少女の 3D モデルが表情豊かに語りかけてくるシームレスな UX を提供.
- **サーバーレスマルチプレイ**  
  プレイヤー間の P2P 同期により、他プレイヤーとの遭遇やボイドの奪い合いを低遅延で実現.

### Client
* **Framework**: Vue 3 (Composition API) + Vite
* **Language**: JavaScript (ESNext) + JSDoc による厳格な型推論
* **2D Game Engine**: Phaser 4 (Arcade Physics, Tiled Map Loader)
* **3D / Avatar**: Three.js, `@pixiv/three-vrm`
* **State Management**: Pinia (`Float32Array` を用いた 1000 パラメータ軽量保持)
* **Event Bus**: `mitt` (Phaser と Vue の疎結合連携)
* **P2P Networking**: WebRTC (PeerJS)
* **Audio**: Howler.js

### Server

* **Framework**: Python 3.12+, FastAPI, Uvicorn
* **LLM Engine**: Ollama (Qwen2.5 / Llama-3 系)
* **Agent / Context**: ターン履歴 + embeddingリコール + Graph RAG (NetworkX)
* **Tool / Search**: SearXNG / Tavily API
